# Support

Start with the repository's README and linked setup documentation. Search existing issues before opening a new one.

For a bug report, include the version or commit, steps to reproduce, expected behavior, actual behavior, and relevant output with sensitive information removed. For a feature request, describe the problem and the outcome you need.

Use the repository's issue tracker when issues are enabled. For a fork, follow its README to find the upstream support channel. Follow the repository's security policy for vulnerabilities; never include credentials or private security details in a public issue.
